# 赛老师 · 会成长的思维陪伴顾问

网页版赛老师——一个能记住你、持续陪伴的混合型咨询顾问。

## 快速开始

```bash
npm install
cp .env.example .env.local
# 编辑 .env.local 填入你的 API Key
npm run dev
```

打开 http://localhost:3000/chat 开始对话。

## 部署

一键部署到 Vercel：

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

部署后在 Vercel 环境变量中设置 `LLM_API_KEY`。

## 技术栈

- Next.js 15 + React 19
- Vercel AI SDK
- Tailwind CSS v4
- 火山引擎 Ark API / Claude API
